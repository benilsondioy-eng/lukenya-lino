# Lukenya Lino — página personalizada

## Estrutura
- `index.html` — página principal
- `style.css` — visual e animações
- `script.js` — animações de entrada e botão de som
- `images/` — fotos

## Música
Para ativar a música, coloca um ficheiro chamado `musica.mp3` na mesma pasta do `index.html`.
O navegador não permite que sites iniciem áudio automaticamente de forma confiável; por isso existe um botão "Som".

## GitHub Pages
1. Cria um repositório no GitHub.
2. Envia `index.html`, `style.css`, `script.js` e a pasta `images`.
3. Se quiseres música, envia também `musica.mp3`.
4. No repositório, abre Settings → Pages.
5. Em Source, escolhe `Deploy from a branch`.
6. Seleciona `main` e `/ (root)` e guarda.
7. O GitHub vai mostrar o endereço da página.
